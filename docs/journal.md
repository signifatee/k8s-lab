## 2026-09-03 — VM падает с I/O error, SSH недоступен

**Симптом:** virsh dominfo показывает I/O error на vda, ssh даёт No route to host.
**Где смотрел:** /var/log/libvirt/qemu/cp-1.log, qemu-img info -U --backing-chain
**Что увидел:** базовый образ 30.5 MiB при virtual size 3.5 GiB.
**Причина:** оборванная загрузка cloud-образа. VM грузилась, пока читала
кластеры из первых 30 МБ, затем упёрлась в конец файла.
**Почему не поймал раньше:** qemu-img check проверяет только метаданные
и на обрезанном файле возвращает "No errors found".
**Решение:** перекачать с проверкой sha256 по SHA256SUMS, chmod 444.


## 2026-09-03 — После пересоздания vm ansible падал на проверке синхронизации времени

**Симптом:** В плейбуке errors=1 и ошибка на шаге проверки синхронизации времени
**Где смотрел:** ansible-playbook site.yml
**Что увидел:** ошибку
**Причина:** vm нужно время на синхронизацию
**Почему не поймал раньше:** впервые ставил скрипт на чистую VM с поднятыми другими VM
**Решение:** retries: 12 И delay: 5 в шаг синхронизации времени
